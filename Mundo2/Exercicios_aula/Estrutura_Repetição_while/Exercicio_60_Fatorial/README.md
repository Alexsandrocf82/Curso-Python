# Exercicio 60 - Cálculo de Fatorial 
## Descrição do Projeto 
O projeto realiza o cálculo do fatorial de um número inteiro não negativo, utilizando a estrutura de repetição `while`.

Foram desenvolvidas três versões para aprimorar o programa, incluindo o tratamento de números negativos e a validação dos dados de entrada.

## Funcionalidades 

1. Versão 1: cálculo básico do fatorial com `while`.
2. Versão 2: verificação de números negativos.
3. Versão 3: validação da entrada utilizando `.isdigit()`.

## Tenologias Utilizadas
1.**Python 3**
2.`while`

## Como Executar

´´´bash
python3 ex04_v1.py
python3 ex04_v2.py
python3 ex04_v3.py
'''
## Aprendizados 

1. **Estrutura de repetição `while`:** aprendi a utilizar contadores e acumuladores para realizar cálculos sucessivos, compreendendo como as variáveis são atualizadas durante a repetição.

2. **Estruturas condicionais `if/else`:** desenvolvi a capacidade de identificar situações inválidas e utilizar condições para controlar a execução do programa, evitando o cálculo do fatorial de números negativos.

3. **Validação de entrada com `.isdigit()`:** compreendi a importância de verificar os dados fornecidos pelo usuário antes de convertê-los para números inteiros, tornando o programa mais confiável.
