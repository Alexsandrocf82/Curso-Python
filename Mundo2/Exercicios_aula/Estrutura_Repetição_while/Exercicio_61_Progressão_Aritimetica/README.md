# Exercício 61 — Progressão Aritmética

## Descrição do Projeto

O projeto realiza o cálculo e a apresentação dos 10 primeiros termos de uma Progressão Aritmética (PA), utilizando a estrutura de repetição `while`.

O usuário informa o primeiro termo e a razão da progressão. A partir desses valores, o programa calcula e apresenta os termos da sequência.

## Funcionalidades

1. Receber o primeiro termo da Progressão Aritmética.
2. Receber a razão da Progressão Aritmética.
3. Calcular os 10 primeiros termos utilizando `while`.
4. Apresentar os termos da sequência no terminal.

## Tecnologias Utilizadas

1. **Python 3**
2. Estrutura de repetição `while`

## Como Executar

Abra o terminal na pasta do exercício e execute o comando:

```bash
python3 ex05.py
```

## Aprendizados

1. **Estrutura de repetição `while`:** aprendi a controlar a quantidade de repetições utilizando uma variável contadora e uma condição de parada.

2. **Progressão Aritmética:** desenvolvi a capacidade de calcular os termos de uma sequência numérica por meio da adição sucessiva de uma razão.

3. **Atualização de variáveis:** pratiquei a utilização de operadores de atribuição, como `+=`, para atualizar o valor do termo e do contador durante a execução do programa.

## Exemplo de Execução

Exemplo utilizando o primeiro termo igual a 3 e a razão igual a 4:

```text
Digite o primeiro termo da PA: 3
Digite a razão da PA: 4
3 -> 7 -> 11 -> 15 -> 19 -> 23 -> 27 -> 31 -> 35 -> 39 -> FIM
```
